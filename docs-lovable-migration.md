# Lovable → GitHub migration notes

The latest Lovable COSMO project contained reusable domain logic and demo data (`cosmo-data.ts`, `cosmo-store.tsx`), but its home route was still Lovable's blank placeholder. This standalone codebase therefore keeps the useful COSMO concepts and rebuilds the missing application shell, customer flows, admin flows, video demo, bilingual UX, QR behavior, Supabase integration layer, and Cloudflare deployment setup without consuming another Lovable generation turn.

Source Lovable project: `Cosmo Proof` (`3a208911-02b4-4460-aa33-f07b0ecab531`).
